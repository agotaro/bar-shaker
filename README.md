# 🍸 Bar Shaker

ブラウザで遊べるバーテンダーゲーム。一週間、バーのカウンターに立ち、常連を増やし、仕入れをやりくりし、無茶ぶりをさばきます。

**遊ぶ:** https://agotaro.github.io/bar-shaker/

## 遊び方

- 客は30人。初日は8人、毎晩3人ずつ新顔が来るようになります。それぞれ好み、来る時間帯、注文の癖があります。
- 夜は19時に開店し、1時半がラストオーダー、2時に閉店。席が空いていれば客が来続けるので、速く捌くほど多くの客をさばけます。客にはそれぞれ来る時間帯があります。
- スコアはパーフェクトの速さ、連続パーフェクトのコンボ、常連度で伸びます。モード別のハイスコアをブラウザに保存します。
- 客はカウンターの席に座ります。席をタップして相手を切り替え、素材をタップしてグラスに入れ、「提供する」。同じ素材は2回まで入れられ、濃いめ・薄めが作れます。
- 注文の種類:
  - **カクテル名**: レシピ通りに。「濃いめで」「薄めで」「ノンアルで」が付くことがある。
  - **〇〇っぽいの**: 半分以上同じで、何か1つ変えると正解。そのまま出すと減点。
  - **今日の気分**: 疲れてる・浮かれてる・落ち込んでる・急いでる。気分に合う一杯を読む。
  - **ふわっとした注文**: 素材の特徴「強・甘・酸・爽・苦・果」の合計で判定。
  - **おまかせ**: 客ごとの好き嫌いで判定。
  - **記憶の注文**: 「前回と同じの」「いつもの」。常連度が上がるほどヒントが減る。「さっきの人が飲んでたやつ」も。
  - **乾杯用に3杯**: 同じカクテルを続けて3杯。
  - **無茶ぶり**: 返し方を選ぶ。時間がかかり、その間ほかの席の機嫌が減る。
- 同じ素材は2回まで入れられ、濃いめ・薄めが作れる。頼まれていない濃すぎ・甘すぎは減点。
- ボトルは夜のあいだ減る一方。切れたら「切らしてまして」と伝えて、客の好みに合う代わりを出せます。閉店後に稼ぎで仕入れます。
- パーフェクトで常連度が上がり、単価が上がります。失敗や放置だと翌日は来ません。
- 家賃が払えなければ閉店です。

## モード

- **腕前**: 見習い（レシピ帳あり・2席）/ 一人前（初回だけ客が作り方を教える・3席）/ マスター（ヒントなし）
- **お金**: のんびり（家賃なし）/ 普通（毎晩の家賃）/ シビア（家賃と仕入れが高い）

## 技術

HTML / CSS / JavaScript の1ファイル（`index.html`）。依存なし。進行はブラウザの localStorage に保存されます。ローカルで遊ぶには `index.html` を開くだけです。
